I'd like to bring up an issue I found which might be worth reviewing: not all the animal skeletals seem to be measured in the same way. Some seem to have their straight-line standing lengths listed while others have their axial lengths along the centra. This might have affected how the tool scales them, which could lead to inconsistent scaling when using the tool vs manual scaling using the gallery skeletals for the same specimens.

You mentioned Giganotosaurus in the post and comments, so I wish to bring up that this one seems to be among the examples where this is noticeable and can be quickly checked with your other illustrations: you've listed the holotype specimen at 12.4 m in your 2013 'North vs South' comparison, but the gallery and tool has it listed at 11.8 m, its straight-line standing length (checked via Photoshop). Taking the type G. carolinii and Sue (which is listed at 12.3 m, same as the NvS 2013 comparison) directly from your gallery and placing them together at the same scale manually, the G. carolinii type ends up being a bit longer which agrees with the 'North vs South' comparison. However using the tool, Sue ends up noticeably longer on the other hand, which is not consistent with both the raw skeletal comparisons and the 2013 comparison.

I've put together this quick illustration with the skeletals themselves to scale, superimposed, and compared with the comparison generated by the tool: https://imgur.com/MBY7Sfc

Hope this helps, and best regards.
